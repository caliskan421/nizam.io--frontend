# WEB-11 — açılmadı

**F11 başlamadı; uygulama işi/işçi/PR açılmadı.** F10'un sonraki faza geçiş kaydıdır, otomatik kapsam taahhüdü değildir.

Son frontend paketi [F10 v0.26 tüketimi](../web-10/README.md); kalanlar [backend eksikleri](../../backend-eksikleri/kayit.md) ve [F10 raporunda](../../backend-eksikleri/rapor-F10.md). Ayrı backend BE-F8 sürecinin sonucu veya daha yeni API etiketi kendiliğinden bu faza alınmaz. Başlangıç koşulu yayımlanmış sözleşme, mevcut ekran kabul eşlemesi ve koordinatörün açık kapsam kaydıdır.

Rol düzeni korunur: Codex yönetici/karar/rapor/PR-CI, Sonnet uygulama ve somut düzeltme, Terra bağımsız test ve gerçek tanık, Opus salt okunur bağımsız denetim. Kapsam seçilmeden audit/Tablolar/profil/Takvim/Asistan veya yeni rol panelleri başlatılmaz.
