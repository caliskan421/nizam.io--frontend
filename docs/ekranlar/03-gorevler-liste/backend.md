# 03 — Backend eşlemesi (nereden geliyor)

Kaynak: `../../../../nizam.io--backend/docs/api/openapi.yaml` (pin `v0.11.0-api`), `istemci-akislari.md`, `error-codes.json`. İstemci uydurmaz; uyuşmazlık `eksikler.md`'ye gider.

Kısaltmalar: **S2** = yalnız `X-Nizamio-Program` başlığı; **S3** = `X-Nizamio-Program` + `X-Nizamio-Department` (tek göreve ait her istek **görevin kendi** satırdaki `program_id` / `department_id` değerleriyle gider, `istemci-akislari.md` §2; aksi 404 `work.item_not_found`). **CSRF** = yazma uçlarında zorunlu `X-Requested-With` başlığı (`attachFile` hariç). **IK** = `Idempotency-Key` başlığı (22–200 bayt, kullanıcı eylemi başına bir kez üretilir, ağ tekrarında aynı anahtar + aynı gövde). Her okumanın ortak hata kodları (tablolarda tekrar edilmez): 401 `platform.unauthenticated`, 403 `identity.force_password_change_required`, 422 `platform.scope_missing`, 429 `platform.rate_limited` (+ `Retry-After`), 500 `platform.internal`/`platform.panic`, 503 `organization.authority_unavailable`/`identity.unavailable`. Yazmalarda ek ortaklar: 403 `platform.csrf_header_missing`, 409 `platform.conflict_retry` (aynı anahtarla tek otomatik tekrar), 409 `provisioning.write_not_allowed`, 413 `platform.body_too_large`, 422 `platform.body_invalid`, 500 `audit.entry_rejected`.

## 4. Türetilen değerler (istemcide hesap)
Hepsi **yüklenmiş satırlar** üzerindedir; `next_cursor` doluyken (daha fazla sayfa var) **yaklaşıktır** (BE-003) ve "yüklenen kayıtlar içinde" / "‹n›+" biçiminde gösterilir. `limit` 200 **sayfa** boyutu tavanıdır, toplam tavanı değil: imleç bitene kadar yüklenen küme tamdır ve sayaçlar kesindir (200'den fazla satır olabilir); imleç bitmemişse sayaç yüklenen kayıtlar içindedir (`ortak-kurallar.md` §10, CX-S-01).

- **Sekme sayaçları (E-03-08):** Başlamadı = `status == baslanmadi`; Devam ediyor = `devam_ediyor`; Onay bekleyen = `onaya_sunuldu`; Geri gönderildi = `iade_edildi`; Tamamlanan = `tamamlandi`; **Geciken = `is_overdue == true`** (sunucu bayrağı; durumla kesişir, tarih hesabı istemcide yapılmaz); Tümü = hepsi. `iade_edildi` **kendi sekmesinde** sayılır (kabul tablosu E-03-07, P5; `eksikler.md` §3 "sekme yok" önerisi ret — Codex CX-F1-K-02 uzlaştırması). Pinli `v0.11.0-api` `WorkItem.status` enum'u beş değer (`openapi.yaml` s.2238); `is_overdue` / `days_overdue` doğrudan `WorkItem` alanları (s.2262, 2264).
- **Tarih talebi sayısı (E-03-09, E-03-13):** `pending_date_request != null` satır sayısı; bant koordinatörlük adları = bu satırların tekil `department_id` → ad (E-03-22 sözlüğü). Departman başına talep uçlarıyla birleştirmek yasak.
- **Gecikme/kalan (E-03-25):** `days_overdue` / `days_late` / `days_early` sunucudan; yalnız "‹n› gün kaldı" = `end_on − bugün` (Europe/Istanbul takvim günü).
- **Arama (E-03-10):** `title` + kısa kod + `assignees[].full_name`, Türkçe katlama (`tr` yerel ayarı, GAP-036) — BE-004.
- **Sıralama (E-03-16):** görev → `title` (`localeCompare('tr')`); durum → enum sırası; bitiş → `end_on`, eşitlikte `created_at`, `work_item_id`. Sunucu sırası sabit `(created_at, id)`.
- **Kişi süzgeci (E-03-11):** `assignees[].account_id` kesişimi; K3 "bana atananlar" = `me.account_id`.
- **Alt görev bloğu eksiklik vurgusu (E-03-33…35 `data-miss`):** yalnız bayraklar sunucuda olunca anlamlı (BE-006); şimdilik `data-req` hep false.
- **Zaman çizgisi (E-03-51):** §1 son satırlardaki alanlardan sentetik olaylar.
- **Panel "Kanıt dosyası" (E-03-50):** `files.length > 0` ise ilk/son dosya adı, yoksa "Yok"; `completion_evidence_required` yalnız "gerekli" bilgisi.

## 6. Sözleşme notları
- `istemci-akislari.md` §2 (program listesi, `department_id` kesişimi, fan-out yasağı, süzgeç seçenek uçları), §3 (ekran → uç; WORK-K83 oluşturma bilgisi), §4 (s. 139–155), §5 (geçiş matrisi; `actor`), §6 (WORK-K82 `pending_date_request`; GAP-204), §7 (kanıt bayrağı; `work.subtasks_open` + `close_subtasks`), §8 (yeniden okuma, iyimser yok, ADR-0027 sürüm + işlem anahtarı, null adlar → "Bilinmeyen kişi").
- `createWorkItem` tek atananla açar; çoklu atama `addAssignments` ile ikinci adımdır (iki yazma; ikincisi başarısız olursa ilk `createWorkItem` isteğindeki `assignee_account_id` korunur; yalnız ilk istekte atanan verilmemişse görev atamasızdır. Kısmi başarı metni ilk yanıtın gerçek durumuna göre yazılır, ör. "görev oluşturuldu, ek atama yapılamadı" — `ortak-kurallar.md` §7, CX-S-03).
- `completion_evidence_required` varsayılanı **true** (ADR-0024): form kapalı göstermemeli.
- Alt görev tarihleri "yalnız bilgi"dir; Gantt, bağımlılık ve gecikmeye girmez, ana görev aralığına sınır doğrulaması yok (ADR-0024, BE-020).
- `attachFile` yükleme bilet akışı değildir (bilet yalnız indirmede, ADR-0013); `tag` zorunlu kapalı küme — tasarımda etiket seçimi yok (`eksikler.md` §3).
- `requestDateChange` ve `transitionWorkItem` IK almaz; sonuç bilinmiyorsa görev yeniden okunup karar kullanıcıya bırakılır.
- `organization.confirmation_required` bu ekranın hiçbir ucunda yok (yalnız üyelik/koordinatör kaldırma uçlarında, F2).
- Tarih biçimi `YYYY-MM-DD` (gün), zaman `date-time` UTC RFC 3339. İki talep listesi sayfasız (GAP-053).
- **`is_overdue` tanımı sözleşmede yok:** "tamamlanmışta hep `false`, açık görevde `bugün > end_on`" tanımı openapi.yaml'da yazmıyor, koddan (`work/domain/lateness.go`) okundu. "Geciken" sekmesi (E-03-07) ve E-03-25 bu tanıma dayanır; sözleşmeye eklenmesi backend belge notudur (`eksikler.md` yeni-6).
