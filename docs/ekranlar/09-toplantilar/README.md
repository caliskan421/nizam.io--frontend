## Özet
Seçili programın ("sezon") toplantılarını gün gruplarına ayrılmış bir liste olarak gösterir (yaklaşan / geçmiş / silinenler), her satırda tarih kutusu, sahip + davetli koordinatörlük kodları, gündem / not / katılımcı sayaçları vardır. Detay sayfası gündem maddelerini (işaretlenebilir, eklenebilir), toplantı notlarını (yazma, süzme, düzenleme/silme, nottan görev oluşturma), katılımcıları düz listede, bağlı koordinatörlükleri ve bilgi kartını gösterir; tasarımda üstteki görüntülü konferans şeridi F4’te gizlidir. Pencereler: yeni toplantı, göreve dönüştür, silme onayı, silinen toplantılar (yalnız admin). Görüşme ekranları (tam ekran ve küçültülmüş pencere) video modülüne aittir; F4'te gizli (BE-023, faz sırası kararı; backend video uçları vardır, sağlayıcı kurulum profiline bağlıdır: `livekit` varsayılan, profil 2'de `none`, GAP-133 karar bekliyor). Admin tümünü görür; coordinatorship kipinde bağlı K ve üyeler dahilse bağlı Ü görür; person kipinde sahip K olan oluşturan yönetir, departman bağı başkalarına görünürlük vermez; iki kipte katılımcı görür (kural kaynağı meetings README K19/K45; `istemci-akislari.md` toplantıyı kapsamaz, bkz. `backend.md` §3). Ana veri kaynağı: toplantı modülü (`listMeetings`, `getMeeting`, not ve katılımcı uçları — eşleme `backend.md`'nin işi).
