# 00 — Backend eşlemesi (nereden geliyor)

Kaynak: `../../../../nizam.io--backend/docs/api/openapi.yaml` (pin `v0.11.0-api`), `istemci-akislari.md`, `error-codes.json`. İstemci uydurmaz; uyuşmazlık `eksikler.md`'ye gider.

Okuma notu: backend çalışma ağacındaki `openapi.yaml` ve `error-codes.json` `v0.11.0-api` etiketiyle aynıdır (2026-11-08 `git diff` boş); yalnız `README.md` ve `compatibility.md` etiketten sonra değişmiştir — bu dosyada o ikisinden alınan bilgi (§6) etiket sonrası metindir.

**Kapsam başlıklarının gerçek adları** (README §3; spec `components/parameters`): `X-Nizamio-Program` (`ProgramScope`, S2/S3 zorunlu), `X-Nizamio-Department` (`DepartmentScope`, yalnız S3 zorunlu). S0/S1 uçlara gönderilen kapsam başlığı yok sayılır; S2/S3 uçta eksikse 422 `platform.scope_missing` (varsayılan kapsama düşülmez). Diğer başlıklar: `Authorization: Bearer <token>` (S1+), `X-Requested-With` (her yazma ucunda zorunlu CSRF, `CsrfHeader`; değer serbest), isteğe bağlı `X-Correlation-Id`. Kabuğun okuduğu uçların çoğu **S1**'dir (başlık gerekmez); kapsam başlığı yalnız kabuk rozetleri için kullanılan S2 uçlarda gider.

## 4. Türetilen değerler (istemcide hesap)
- **Baş harfler** (E-00-28, E-00-32): `me.full_name` → ilk iki sözcüğün ilk harfleri, Türkçe büyük harf (`tr-TR`; GAP-036 katlama notu). 
- **Program avatarı** (E-00-04, E-00-07): harfler `Program.name`'den, renk `program_id`'den deterministik — BE-001 kapanana dek `designStub('BE-001', …)`.
- **Program alt metni** (E-00-07): `year` varsa `"<year> sezonu"`; yoksa alt metin gizli. **Varsayım:** "sezon" ifadesi `year`'dan kurulabilir; `year` program adına zaten gömülü olabilir (ürün sahibine soru).
- **Mercek listesi ve sayılar** (E-00-05, E-00-08): yukarıdaki §3 kuralları; sayı satır sayısıdır (aynı departman aynı programda iki rolde olamaz — **Varsayım**, ekip satırı tekil; doğrulanacak).
- **Birim listesi** (E-00-09): `myDepartments` satırları `program_id == seçili ∧ role == mercek`; sıralama `display_name`'e göre istemcide (sunucu sırası spec'te belirtilmemiş).
- **Kapsam çözümü:** hatırlanan `programId` `listPrograms` içinde değilse düşer; hatırlanan `departmentId` seçili program + mercekteki satırlarda değilse düşer; tek seçenek varsa otomatik (K2). Admin merceğinde istekler yalnız `X-Nizamio-Program` ile gider; Koordinatör/Üye merceğinde departman, görev listesi için `department_id` **sorgu parametresidir** (S2), S3 uçlarda `X-Nizamio-Department` başlığıdır.
- **Rozetler:** Admin merceği E-00-14 = `reportDashboard.overdue_tasks`, E-00-15 = `pending_date_changes`; 0 ise gizli. Koordinatör/Üye merceği: gizli + `designStub(<yeni-3'e verilecek BE kimliği>, …)`. Admin değerleri GAP-075 nedeniyle testsizdir. Liste satırlarından (`listProgramWorkItems` → `is_overdue`, `pending_date_request != null`) sayım **yalnız yüklenmiş sayfa için** doğrudur; kabuk rozeti için bütün sayfaları gezmek her ekranda tam tarama maliyeti demektir ve yapılmaz; bu, aynı ucun sayfalaması olduğundan K3 fan-out yasağı değil maliyet kararıdır (ortak-kurallar §9; istemci-akislari §2/§6; CX-T-05).
- **Okunmamış mesaj** (E-00-21, F7): `items.find(program_id == seçili)?.unread_chats ?? 0`.
- **Zil** (E-00-38): `count > 0` → nokta; erişim adı sayıyı içerir. Üst sınır biçimi (ör. "99+") tasarımda yok.
- **Tarih** (E-00-36): `Intl.DateTimeFormat('tr-TR', { timeZone: instanceProfile.timezone, … })`.

## 6. Sözleşme notları

- **Kapsam:** README §3 (başlık adları başta). Kapsam başlığı yetki kanıtı değildir; kapsam dışı kayıt 404 döner.
- **K6 yetki kaybı — hangi kod hangi uçtan** (spec `x-nizamio-error-codes` taraması):

- **Liste sınırları:** `myDepartments`, `listPrograms`, `listProgramDepartments` imleçsiz ≤200 + `X-Result-Truncated: true` (README §4, GAP-027); kesilmişse menüde "liste eksik olabilir" uyarısı gerekir — tasarımda yok. `MyDepartmentList.departments` `nullable: true` → `null` boş dizi sayılır.
- **Sürüm kapısı:** README §7–8, compatibility.md §2–3: `api_version` yalnız ana sürüm (`v1`); "güncelleme gerekli" yalnız ana sürüm farkında tetiklenebilir. Etiket uyumsuzluğunu (ör. web `v0.11.0-api`, sunucu `0.12.x`) yakalamak için web kuralı yok — mobil `server_version` MAJOR.MINOR ile yapıyor; web için yeni-2 (belge + koşullu BE). Ürün sürümü ile API pin minörünü karşılaştıran uyarı **yapılmaz** (ortak-kurallar §11).
- **Hata zarfı:** README §5 (`code`, `message`, `request_id`, ops. `correlation_id`, `fields[]`, `details`). 429'da `Retry-After`; otomatik tekrar yok (K5).
